# Injected-bug targets, PR by PR

The catch rate counts one injected bug per PR. This table shows, for each of the 50 PRs in Martian's dataset: the one-line description Greptile's benchmark page gives for that PR's bug; the target our scorer uses (a golden comment from Martian's dataset, a keyword rule, or a hand-judged definition where the injected bug has no golden comment of its own); Aether v22's result under our grading; the result of Greptile's own July 2025 review of the same PR under our grading; and whether Greptile's page ticks that PR for itself. Greptile's page numbers the PRs 1 to 10 per repository (2 to 11 for cal.com) in the order Martian's dataset lists them; we matched the two lists by content and the PR titles agree.

On 40 PRs the two descriptions name the same bug. On four (cal.com 10600 and 22345, Keycloak 38446, Grafana 97529) the framing differs or the scorer accepts a wider set than Greptile's one line. On five (sentry-greptile 1 and 5, Grafana 76186, 90939 and 103633) Greptile's one-line description does not match the PR as distributed, in Greptile's own July fork as much as in Martian's copy, and we score the golden comment Martian lists or the defect the code actually has; those rows say why. v22 catches 4 of those five, so counting all five as misses gives 38 of 50 instead of 42. On sentry 95633 the target was hand-defined on 19 October after the keyword rule was found to credit any mention of ShutDown.

Sources: Greptile's page, https://www.greptile.com/benchmarks (fetched 19 October 2026), and its July 2025 review PRs under github.com/ai-code-review-evaluation; Martian's golden comments, `offline/golden_comments/`; the scorer's target table, `offline/scripts/aether_greptile_score.py`; decisions, `offline/handjudge/aether-v22.json` and `offline/handjudge/greptile-2025-07.json`. "flagged" means the decision file marks the catch as a judgment call.
